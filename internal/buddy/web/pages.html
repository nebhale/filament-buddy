Printer setup

Copy these snippets into your slicer’s custom G-code fields.

Before you begin

Configure your printer and Spoolman connection in the configuration file, then restart Filament Buddy. Check that the spool catalog is available in the app.

Using both Buddy apps?

Use the same relay destination for both apps. Samplicator copies metrics to each app. Keep both apps’ snippets, and point every M334 at the relay’s LAN address and port. Approve the metrics destination on your printer if prompted.

What happens next

A START marker opens a session. Each CHANGE marker completes a filament section and opens the next. A STOP marker completes the final section and closes the session.

If START is not received, the first CHANGE marker opens a recovered session. Missing CHANGE markers leave sections with unknown weight. A STOP marker without an active session does not open one.

Start, color change, and end blocks each send three markers, 1.1 seconds apart: 2.2 seconds of waiting at each boundary. This spreads retries across firmware metrics packets. Copy updated blocks and re-slice for changes to take effect.

After a manual close, CHANGE markers are ignored until a new START marker or application restart. A new START marker also closes an unfinished previous session. Active sessions survive application restarts; there is no inactivity timeout.

Long filenames or names containing characters other than ASCII letters, digits, spaces, underscores, periods, and hyphens use Print as a fallback to fit the printer’s metric limit. The session timestamp helps distinguish these prints.

Weights are slicer estimates for single-extruder, manual M600 color changes. Set the filament preset’s density correctly. Weight is reported only at a color change or print end; firmware-controlled purge and other unreported extrusion may need a manual correction. No layer-change snippet is needed.

Sessions and their adjustment history are kept indefinitely. Assign a spool to every section before archiving a closed session. Saving No spool on an archived session automatically restores it to the print library. Archiving never changes spool adjustments. The Spoolman catalog refreshes every minute and includes archived spools for historical corrections.
